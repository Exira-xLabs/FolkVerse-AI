# Hybrid explanations and independent factual support

Implemented 7 October 2026. The live guide uses the `hybrid_sections_v1` contract; the former excerpt contract remains readable for recorded fixtures.

Jinyao can combine source-backed statements with plain-language educational context in English or Chinese. Each section carries its own visible support label. General explanations have no citations and are explicitly not fact-verified. They cannot supply specific local dates, people, origins, quotations, URLs or current schedules. Labels do not establish general-knowledge correctness.

The provider proposes structured JSON. The server independently checks schema, locale/depth, exact permitted statements, passage/source IDs, classification, qualifiers, required supporting sources and complete display mappings. Supported statements are complete reviewed passages, actual human-approved variants, eligible complete sentences or closed inventory projections. Official-page metadata uses a separate closed projection. Arbitrary factual paraphrase and model self-assessment are not accepted support methods. A rejected grounded claim rejects the proposal; it cannot be moved into a general section. Unsupported precise questions return an explicit coverage limit.

The browser independently verifies the published claim/section/source mappings. No factual text is displayed before the complete validated SSE terminal frame. Source inspection rechecks eligibility; withdrawal removes the affected answer and consented context. Sessions and evidence are checked again before publication. Consented follow-ups use signed evidence versions, never earlier model prose as evidence.

## Trusted lookup

The registered directory includes 189 original official cultural-profile URLs discovered during collection, with 42 bilingual search aliases. Aliases are discovery aids, not reviewed translations. Exact-title/alias or sufficiently specific directory matching chooses the original page; ambiguous matches request clarification. This is bounded directory search, not unrestricted web search or exhaustive coverage.

Only exact registered HTTPS hosts are allowed. Each redirect and DNS result is checked; the transport connects the validated public IP with the original TLS hostname. Robots rules, no credentials/environment proxies, time/byte/concurrency limits and compressed-response rejection bound acquisition. Page text remains untrusted data. Only closed metadata/founding-date projections and bounded native-language excerpts are offered as claims. An institution's statement is attributed rather than declared historical truth.

Official lookup shows original URL, institution and fetch time, with **editorial review pending**. It never changes corpus approval. Cache entries expire after five minutes and changed page hashes invalidate dependent answers. Current opening hours, prices and schedules remain unavailable: a newly fetched old profile is not current operational evidence. Broader facts, conflicts and translation require actual reviewed units/variants.

## Human-reviewed publication

`pnpm data:liaoning:publish -- --unit <unit-id>` is an explicit operator action after content, source and rights approval. Pending or stale review hashes fail closed. Published units join retrieval with their real supporting-source IDs and classifications; changing/revoking dependencies removes eligibility. This delivery publishes no new drafts. The stored eligible collection remains two passages for one exhibit.
