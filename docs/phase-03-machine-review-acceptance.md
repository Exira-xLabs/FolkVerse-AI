# Phase 3 autonomous source assessment

Owner instruction, 7 October 2026: “i am not reviewing this as a human. finish phase 3”.

Codex takes responsibility for source comparison, bilingual editorial assessment, evaluation and regression checks. Owner ratings are no longer an acceptance dependency. This changes the review method, not the whole-Liaoning geography or the factual-support rules. No human or specialist approval is claimed.

Human-approved corpus publication remains a separate protected workflow. The 448 old drafts retain their original pending status. A separate machine assessment covers 42 concise bilingual official-profile summaries, three topics per city across at least two subjects. Codex inspected the captured original paragraphs, removed an unsupported Wunushan draft assertion and corrected the inherited Panjin museum name and retained explicit folklore attribution. The runtime fetches the original official page and requires its raw and paragraph hashes to match before using those summaries. Changed or unavailable originals cannot silently preserve the old summaries. Visitors see that Codex assessed the summary and that no human review occurred.

The [machine launch manifest](../data/liaoning/machine-launch-manifest.json) records all 14 cities, bilingual introductions, topic contexts/examples and follow-up prompts. It is a baseline of usable explanations, not an exhaustive encyclopedia. The existing inventory and research backlog remain the route to broader coverage. Current opening hours, prices and schedules still require a dedicated current-information adapter; the chatbot explicitly declines these when unsupported.

Phase 3 acceptance uses source-bound factual support, citation freshness, classification, actual bilingual delivery, consented context, understandable presentation, personality behavior, fault handling, accessibility and reproducible startup. A machine assessment is not an independent expert quality score. General explanations remain visibly unverified; structural validation does not establish their truth. Independent specialist review can strengthen later content releases without requiring the owner to fill a worksheet.

The 200-question live pilot retains its own gate. Its dataset contains 100 paired families: all 42 topics, unavailable current-information requests in every city, concepts, conversation and follow-ups. Questions were frozen before the first run. The initial topic subset was exposed while fixing attribution-copy failures; later reruns must be labelled accordingly. Provider limits and the owner's existing spending cap remain enforced.
