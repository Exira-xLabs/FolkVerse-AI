# Temporary visit state and selected exhibit context

5 October 2026 — Part C UI contracts. These are browser UI behavior, not Phase 03/04/06/07 service completion.

Guide drafts and at most twenty scripted question/answer turns live only in the root React visit provider. They survive internal navigation and language changes during the current document's lifetime. Reloading or closing clears them. Clear conversation removes both draft and history; an outstanding scripted response cannot restore a cleared turn. Questions are bounded to 2,000 characters. No local/session storage, analytics, model call or server save stores this text. History is not used as AI context; all answers remain explicitly scripted. A later real conversation must define owned session storage, consent, context selection, deletion and streaming under Phase 03.

Journey's example stop order, removals, time and interest criteria use the same in-memory lifetime. The selected time/interests are draft criteria. The route's badge uses its last applied time; changing criteria marks the route out of date until Apply regenerates it. Reset example plan restores the original examples and criteria. The tour is explicitly separate from Liaoning and contains the existing Shaanxi, Fujian and Guangdong fixtures. Durable save, real route generation and ownership belong to Phase 04.

An exhibit's `exhibit` URL parameter carries its identifier from the published drawer into Guide, Journey, Story and interests, and back to the exact source drawer. Each destination retrieves the current published record, refreshes on focus and every fifteen seconds, suppresses results for earlier identifiers/locales/requests, and clears display/actions on withdrawal or failure. Retaining an identifier is not authorization to publish a draft record. Invalid and unavailable records fail closed.

Guide can explicitly seed an editable question about a currently available exhibit in demo mode; reveals/focuses the composer and bounds the draft to 2,000 characters; it never submits automatically. Clear conversation keeps the independently selected exhibit context. Normal navigation without the exhibit parameter leaves that context. Live mode shows the reviewed context and available return link but exposes no scripted composer. Journey offers reading as the available starting action. Story labels its original fiction as a separate example, not an adaptation of the record. Interests do not change automatically from an exhibit; real recommendations remain unconnected.

Region's only province-wide choice is All Liaoning. It sends `region_id=liaoning`, including descendant cities, rather than an unfiltered cross-province query. Map publication indicators distinguish checking, service failure, published-city availability and no published records; geography is separate from publication status. Required atlas attribution is preserved.

The story offers the actual English recording or text only, with its exact English transcript and a labelled Chinese translation. Chinese audio is explicitly unavailable. Guide microphone transcription is also unavailable and disclosed before any action; the disabled control explains typing as the available alternative. No microphone permission is requested.
